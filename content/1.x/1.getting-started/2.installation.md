## Requirements

- PHP **8.3** or higher
- Laravel **13**

Optional:

- [Laravel Scout](https://laravel.com/docs/scout) **11**, for controlled searches.
- [Laravel Rest Api](https://laravel-rest-api.lomkit.com) **3.6** or higher, for its extension, which applies your controls to every rest-api resource.

::note
Applications on Laravel 12 can use version [0.7](https://github.com/Lomkit/laravel-access-control/releases/tag/v0.7.0), the last 0.x release. Moving an application from 0.x to 1.x is covered in the [upgrade guide](/getting-started/upgrade-guide).
::

## Installing Laravel Access Control

Install the package with Composer:

```bash
composer require lomkit/laravel-access-control
```

Laravel discovers the service provider of the package. There is no configuration file to publish: everything is declared in your controls.
